Install and use

On your computer

Download and_Lubrifont from the Releases page and install all six .ttf files. Uninstall any older WD-XL Lubrifont or and_Lubrifont first.

Bold and Italic are linked to the Regular, so the bold and italic buttons of your application use the real styles. Light appears as its own entry, and_Lubrifont Light.

Writing Chinese or Japanese as well? Take the and_Lubrifont-CJK download instead.

On a website

The download has WOFF2 web fonts in woff2/. One rule per style:

@font-face {
  font-family: "and_Lubrifont";
  src: url("andLubrifont-Regular.woff2") format("woff2");
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}
/* Light 300, Bold 700; the Italic files
   with font-style: italic */
